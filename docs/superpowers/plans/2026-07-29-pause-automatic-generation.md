# Pause Automatic Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a user pause the unattended 8am cron generation on `/account`, indefinitely, without affecting on-demand generation.

**Architecture:** Add a nullable `paused_generation_at` timestamp to `users`. `GenerateDailyExercisesJob`'s cron (no-`user_id`) batch path excludes users where it's set; the on-demand (`user_id:`) path ignores it entirely. A new `PATCH /account/toggle_generation` action on the existing `AccountsController` flips it, with a small UI section on `/account`.

**Tech Stack:** Rails 8.0.5, PostgreSQL, RSpec (request + job specs), no JS framework (this feature needs no client-side script — it's a plain form POST).

## Global Constraints

- Migration file naming: `db/migrate/YYYYMMDDHHMMSS_verb_noun.rb`, using `ActiveRecord::Migration[8.0]` (see `db/migrate/20260727000000_add_last_generation_error_to_users.rb`). Use `20260729120000` as the timestamp for this migration (later than all existing migrations as of this plan).
- Nullable timestamp columns on `users` are the established pattern for optional state (`last_generation_error_date`, `anonymized_at`) — no boolean column, no separate table.
- Route style: singular `resource :account` block in `config/routes.rb`.
- On-demand generation (`GenerateDailyExercisesJob#perform(user_id:)`) must NOT check `paused_generation_at` — only the no-arg batch path does.
- Flash notice copy must be exactly: `"Automatic daily generation paused."` and `"Automatic daily generation resumed."`
- Account page copy must show: `"Automatic generation is active"` when not paused, and `"Automatic generation is paused (since <date>)"` when paused (date formatted via `l` or `strftime("%B %-d")`, matching this file's existing date display conventions — there are none yet on this page, so use `paused_generation_at.to_date.strftime("%B %-d")`).
- Button label must read `"Pause automatic generation"` when active, `"Resume automatic generation"` when paused.

Replace with:

```ruby
  # DELETE /account
  # Synchronous and irreversible. Double-submission is safe twice over: once
  # anonymized, `current_user` returns nil so `require_login` redirects before
  # this ever runs, and `anonymize!` no-ops regardless.
  def destroy
    current_user.anonymize!
    reset_session
    redirect_to login_path, notice: "Your account has been deleted."
  end

  # PATCH /account/toggle_generation
  # Flips paused_generation_at between nil and now. Only affects
  # GenerateDailyExercisesJob's unattended cron batch path — on-demand
  # generation (dashboard open, /generate) is unaffected either way.
  def toggle_generation
    if current_user.paused_generation_at?
      current_user.update!(paused_generation_at: nil)
      redirect_to account_path, notice: "Automatic daily generation resumed."
    else
      current_user.update!(paused_generation_at: Time.current)
      redirect_to account_path, notice: "Automatic daily generation paused."
    end
  end
end
```
