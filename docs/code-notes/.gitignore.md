# .gitignore

Files an editor or operating system generates belong in git's global ignore (`$XDG_CONFIG_HOME/git/ignore` or `~/.config/git/ignore`), not in this file. Rails generated the rest of the file; the lines below say what each group holds.

- Bundler config (`/.bundle`) and environment files (`/.env*`).
- Logs and temporary files, with `.keep` files kept so the folders exist. This includes pidfiles and the development storage folder (uploaded files and any SQLite databases).
- `/config/master.key`, which decrypts the credentials.
- `node_modules` for the Playwright CLI (`spec/playwright`) and for Prettier (`vendor/prettier`), restored from their lockfiles.
- `.superpowers/`, scratch from subagent-driven development (ledger, briefs, review packages).
- `/spec/examples*.txt`, the `--only-failures` state RSpec keeps, one file per `parallel_tests` process.

`bin/comment-check` reads a `.gitignore` comment only when the line starts with `#`. A `#` later in a line is part of the pattern, and `\#` matches a literal hash.
