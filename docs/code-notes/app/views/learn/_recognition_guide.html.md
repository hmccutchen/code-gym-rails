# app/views/learn/_recognition_guide.html.erb

## The `<details>` disclosure

The disclosure exists only to keep the Learn index scannable. Nothing gates it:
the guide teaches a way of looking, never an answer, so every user sees it.

## Labels

The labels are paragraphs rather than headings. The guide sits under an `h2`
in a flat bucket and under an `h3` in a named group, and no single heading
level fits both.
