# db/migrate/20261104180000_drop_users_name.rb

Release 2 of #686. Release 1 (#688) stopped writing and validating `users.name`
and made `User` ignore it, so web and worker both run code that never reads the
column and the drop cannot break a running process.

`up` drops the column only if it exists, since a pull-request app or a
development database may already have lost it. `down` adds it back required with
the placeholder default `Member`, the shape release 1 left, so a rollback
restores a table the previous release can insert into. Names stored before the
drop are gone for good.
