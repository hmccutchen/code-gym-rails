# .rubocop.yml

## Which files RuboCop skips

`AllCops: Exclude` lists every folder RuboCop skips, and `inherit_mode: override: [Exclude]` inside `AllCops` makes that list replace the inherited ones instead of adding to them. The inherited lists are RuboCop's own (`.git`, `node_modules`, `tmp`, `vendor`), rubocop-rails' (`app/assets`, `bin/*`, `db/*schema.rb`, `log`, `public`, `storage`) and rubocop-rails-omakase's (`data`).

The list restates all of them except rubocop-rails' `bin/*`. CLAUDE.md's comment rules hold in every file, and with `bin/*` excluded nothing checked `bin/setup`, which had grown to eight comments, among them commented-out code (#755). A merged list cannot drop one inherited entry, so the override is the only way to take `bin/*` out. The cost is that a folder a later RuboCop or rubocop-rails version adds to its own excludes is not skipped here until someone adds it to this list.

The override has to sit inside `AllCops`. A top-level `inherit_mode: override:` does not win, because omakase's top-level `inherit_mode: merge: [Exclude]` is merged into the same setting, and at the top level RuboCop only looks at `merge`.

RuboCop picks the Ruby scripts in `bin/` by their `#!/usr/bin/env ruby` shebang, so `bin/docker-entrypoint`, a bash script, stays out without a list of its own. `bin/comment-check` reads that one (`docs/code-notes/lib/comment_check/scanners.md`).

## Every cop applies to bin/

`bin/` gets the same cops as the rest of the repository: omakase's style cops, the three house comment cops and the three `Lint` cops `.rubocop.yml` turns on. That set is already small, the `Metrics` cops are limited to `app/` by their own `Include`, and the scripts Rails generates into `bin/` follow omakase, so only `bin/setup`'s comments needed changing. A narrower set for `bin/` would need its own config and gain nothing.

## Running it inside a worktree

RuboCop takes `AllCops: Exclude` from the highest `.rubocop.yml` above the file being checked as well as the nearest one. A worktree under `.claude/worktrees/` sits inside the main checkout, whose `.claude/**/*` exclude then matches every file, and RuboCop reports 0 files inspected. Run `bin/rubocop --ignore-parent-exclusion` there. `spec/conventions/repo_files_spec.rb` sets the same option when it asks RuboCop which `bin/` files it reads.
