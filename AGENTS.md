# Coding Gym repository instructions

Read [CLAUDE.md](CLAUDE.md) before starting repository work. It is the shared
source for the project workflow, coding standards, architecture, and test
requirements. Its repository rules apply to every agent.

Follow the Area rules section in `CLAUDE.md`. If your tooling does not load
path-scoped instructions automatically, read the applicable files in
[`.claude/rules/`](.claude/rules/) before opening files that match their
`paths:` globs. Use the linked decision records and
[file map](docs/file-map.md) to find the relevant design and implementation.
